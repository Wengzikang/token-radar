Token Radar ranks 120 pre-token protocols from a sealed DefiLlama snapshot by the implied value a token would carry, from TVL, seven-day growth, age listed and chain breadth — and gives each one a concrete six-step farm plan. The dashboard is a static page with a sortable, filterable board and a detail view per protocol.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
